# 📝 To-Do List App

A simple and responsive To-Do List application built using HTML, CSS, and JavaScript.

## 🚀 Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 🔍 Search tasks instantly
- 📊 Task Counter
  - Total Tasks
  - Completed Tasks
  - Pending Tasks
- 🧹 Clear All Tasks
- ⌨️ Add tasks by pressing the Enter key
- 📱 Responsive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
